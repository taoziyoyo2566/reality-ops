## Intent

- **A1 D1-B 闭合本机绕过**：放行 = 「确经 CF 边缘」(CF Transform Rule 注入 `X-Monitor-Tunnel-Secret`，`hmac.compare_digest` 校验) **且**「客户端 IP ∈ 运维白名单」；否则要 Bearer。本机进程无 secret 头 → 即便伪造 `CF-Connecting-IP` 也被堵；外部经 CF 但非白名单 → 被堵。secret 未配时 **fail-closed**（只认 Bearer），故 CF 未配好前部署也安全。
- **仪表板零改动**：浏览器经 CF 域名访问，CF 自动加 secret 头 + 运维 IP 白名单 → `fetch`/export 原样 200。
- **最小权限 + secret 隔离**：server 以非 root `reality-monitor` 运行；5 个敏感 token 移出世界可读的 server.py，入 0600 env（仅 server 用户可读）。
