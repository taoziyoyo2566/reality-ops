- **A2 采集可靠性**：把"丢数 + 重启幻象尖峰"根治。`last` 始终推进到当前计数器（增量正确），欠量进 `pending`（单值/用户，非无界 list，避免磁盘堆积），仅 HTTP 200 才推进/清 pending（4xx/5xx 不再误判成功）。首见/重置上报 0 而非累计值，根除 46GB 单分钟尖峰。原子写防半截损坏文件；flock 防 cron 重叠双计（与 A3 的整点抖动叠加更需要）。

- **token 外置 + 专用用户**：report_token 移出世界可读脚本到 0600 文件；agent 以 `reality-monitor-agent`（docker 组）运行，不再 root cron。
