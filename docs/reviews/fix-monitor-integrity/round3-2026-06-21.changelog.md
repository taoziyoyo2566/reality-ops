## Intent

- **A3**：根治整点惊群 `database is locked`。WAL（DB 级持久）使读写并发不互锁；`busy_timeout` 让 SQLite 自身在锁冲突时等待重试（canonical 机制，故未加应用层手动重试循环）；写端点同步 `def` 自动入 Starlette 线程池，不阻塞事件循环。
- **B4**：`/stats/ip_report` 原同时要 `auth_guard`（白名单/Bearer）+ token，而 agent 只发 token、节点 IP 不在白名单 → 上报被 401 静默丢弃（IP 审计死因之一）。对齐为与 `/report` 一致仅校验 `REPORT_TOKEN`。⚠️ 完整恢复 IP 审计还需 agent 侧 B3（日志路径）+ B5（正则）——下一轮。
